Retained foundations include the shared header/footer, responsive navigation, homepage composition, service cards, calculator, process, location directory, state and city page shells, four deterministic hero layouts, inventory catalog, FAQ, quote-planning form, static prerenderer, sitemap generator, and data integrity tests.

Target adaptations include domain metadata, restroom-first identity, phone-number removal, JSON-exact location H1/description rendering, target CTAs, and target GitHub/Vercel configuration.
